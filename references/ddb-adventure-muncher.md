# DDB Adventure Muncher

**Repository:** https://github.com/MrPrimate/ddb-adventure-muncher

## Overview

The DDB Adventure Muncher is a desktop application that extracts adventures from D&D Beyond and imports them into Foundry VTT as adventure compendiums. It's designed to work with the DDB Importer module to create complete adventure imports with scenes, journals, tokens, and more.

## Key Features

- **Adventure Munching**: Converts D&D Beyond adventures into Foundry VTT adventure files
- **Scene Support**: Includes enhanced scene data with walls, lighting, and tokens
- **Cross-Platform**: Available for Windows, Mac, and Linux
- **Command Line Interface**: Supports command-line operations for automation
- **Token Generation**: Automatically places tokens from monster compendiums
- **Enhanced Content**: Integrates with ddb-meta-data for improved scene information

## Main Components

### Adventure Processing
- Downloads adventure content from D&D Beyond
- Processes journals, scenes, tables, and handouts
- Generates Foundry VTT compatible data structures
- Handles image assets and linking

### Scene Enhancement
- Wall and lighting placement
- Token positioning and configuration
- Note and pin generation
- Grid alignment and scaling

### File Management
- ZIP archive creation for adventure packs
- Asset downloading and organization
- Compendium generation

## Configuration
The application requires a configuration file generated by the DDB Importer module in Foundry VTT, which includes authentication tokens and output directory settings.

## Integration Points
- Works with **ddb-importer** for character and compendium data
- Uses **ddb-meta-data** for enhanced scene information
- Outputs to Foundry VTT as adventure compendium packs

## Command Line Usage
```shell
./ddb-adventure-muncher generate <book-code>  # Generate specific adventure
./ddb-adventure-muncher list                  # List available books
./ddb-adventure-muncher download              # Download book files
```
