# D&D 5e System for Foundry VTT

**Repository:** https://github.com/foundryvtt/dnd5e

## Overview

The official Dungeons & Dragons Fifth Edition game system for Foundry Virtual Tabletop. This system provides comprehensive support for D&D 5e rules, character management, and gameplay mechanics within the Foundry VTT platform.

## Key Features

### Character Management
- **Complete Character Sheets**: Full D&D 5e character sheet implementation
- **Advancement System**: Automated leveling and feature acquisition
- **Ability Score Management**: Comprehensive ability score tracking
- **Skill and Proficiency System**: Complete skill and proficiency management

### Document Types
- **Actors**: Characters, NPCs, and creatures
- **Items**: Equipment, weapons, armor, spells, and features
- **Spells**: Full spell system with slots and preparation
- **Features**: Class features, racial traits, and feats

### Game Mechanics
- **Combat System**: Initiative, actions, and turn management
- **Spell Casting**: Spell slots, preparation, and casting mechanics
- **Conditions**: Status effects and condition tracking
- **Currency Management**: Coin tracking and conversion
