# Foundry Virtual Tabletop Core

**Repository:** https://github.com/foundryvtt/foundryvtt

## Overview

Foundry Virtual Tabletop is a modern, self-hosted, and feature-rich tabletop gaming platform. This repository serves as the issue tracker and documentation hub for the core Foundry VTT software, which provides a comprehensive framework for digital tabletop gaming experiences.

## Core Architecture

### Application Framework
- **Electron-based**: Cross-platform desktop application
- **Node.js Server**: Self-hosted server architecture  
- **Modern Web Technologies**: HTML5, CSS3, WebGL, and JavaScript
- **Real-time Communication**: WebSocket-based multiplayer support

### Document System
- **Unified Document Model**: Standardized data architecture
- **Embedded Documents**: Hierarchical document relationships
- **Database Integration**: NeDB for data persistence
- **Migration System**: Automated data structure updates

### Canvas System
- **PIXI.js Rendering**: Hardware-accelerated graphics
- **Layer Management**: Organized rendering layers
- **Interactive Objects**: Tokens, tiles, lights, and sounds
- **Dynamic Lighting**: Advanced lighting and vision systems
