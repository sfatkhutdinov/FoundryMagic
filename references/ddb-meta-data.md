# DDB Meta Data

**Repository:** https://github.com/MrPrimate/ddb-meta-data

## Overview

The DDB Meta Data repository contains scene enhancement data and metadata for D&D Beyond adventures imported into Foundry VTT. It provides wall placements, lighting configurations, token positions, and other scene enhancements that make imported adventures more playable.

## Key Features

### Scene Enhancements
- **Wall Data**: Precise wall placement for maps and scenes
- **Lighting Configuration**: Dynamic lighting setups for atmospheric scenes
- **Token Placement**: Pre-positioned tokens from monster compendiums
- **Grid Alignment**: Proper scaling and positioning of battle maps
- **Scene Notes**: Pin placements and handout references

### Supported Content
- Covers most official D&D Beyond adventures
- Includes scene data for campaign books
- Supports one-shot adventures and supplements
- Regular updates for new content releases
